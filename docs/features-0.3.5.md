# v0.3.5 — Techniques and licensed icons

The new **EoC · Book Techniques** pack contains all 123 Technique cards from the supplied Shinobi Playtest v1.0 PDF, pages 76–100: 31 Bukijutsu, 28 Genjutsu, 43 Ninjutsu, and 21 Taijutsu. Folders use **Type → Element → Rank**. Fuinjutsu is supported by the sheet and has a reserved top-level folder; the supplied book has no Fuinjutsu cards. Existing expansion Techniques remain in **EoC · Technique Expansion**, with their original pack identifier retained for existing UUID links.

Technique and legacy Jutsu Items share the full sheet: five types, E–S ranks, Chakra/AP costs, Instantaneous/Maintained/Passive/Internalized durations, Attack/Movement/Special/Reaction actions, the requested range bands, and optional Ray/Cone/Explosion templates. Other/variable ranges and original range text preserve cards whose range is weapon-dependent or expressed only as an area template. Raw rank, duration, and cost rules are retained alongside dropdown selections.

**Use** immediately deducts fixed costs from the owning Actor's current Chakra and remaining AP. Variable-cost Techniques ask for the total for the selected variant, clones, items, or targets. Insufficient resources, invalid inputs, and drafts spend nothing. Uses on the same Actor are serialized to prevent rapid clicks from overwriting resource deductions. The existing New round control restores the round's AP. Upkeep, hit results, targets, and special effects remain resolved using the card's rules.

Hidden Needles uses its printed **maximum Chakra Pool** cost: Use reserves capacity on the Actor and spends AP; **End** restores the reserved capacity without refilling current Chakra or AP. Deleted owned Techniques no longer contribute reservations. Enma Ibuki is imported as a draft because the source card lists a generic unresolved cost/duration table. Its rules are preserved rather than choosing a cost not specified by the book.

**EoC · Heritage Expansion** contains all 21 named Heritages in the linked expansion, arranged in Core, Hidden Leaf, and Other Heritages folders. All 63 Boon entries and 63 Bane entries preserve their supplied Genin/Chunin/Jonin tier, including source placeholders. Named unfinished Heritages remain marked draft; blank Heritage Template examples are excluded. Source: https://docs.google.com/document/d/1QCJvpelbQ4wGB9_fyRFQEhTpTUclmlrRjNnUEDXawJA/edit

RPG-Awesome UI glyphs and Game-icons.net document/discipline images are bundled locally for Linux and offline Foundry installations. [Icon credits](../ICON-CREDITS.md) list each SVG's author, source, and license. BSD 2-Clause, CC-BY-3.0, SIL OFL 1.1, and MIT notices ship in `licenses/`. The README includes repository-page attribution; publishing it remains a manual Git operation.

Source imports are reproducible with `tools/import-book-techniques.py`, `tools/import-heritages.py`, and `tools/import-icons.py`. Refresh the expansion's plain-text export in `tmp/heritage-expansion.txt` before reimporting. `npm run build:packs` builds stable Item and Folder IDs; real Foundry verification checks all 324 Items, internal folders, Technique dropdown values, and Heritage tier assignments.
